# Zatvor

English version: [README.en.md](README.en.md)

**Статус: в разработке.** Устанавливать пока нечего.

Zatvor — бесплатный настольный клиент, который (1) запускает Xray-core и принимает всё, что принимает клиент Happ, (2) не даёт выбранным приложениям использовать недопустимый публичный адрес (их замораживают, затем закрывают или отрезают от сети) и (3) направляет российский трафик напрямую, а ИИ-сервисы, заблокированные сайты и инструменты разработчика — через туннель. Он рассчитан на неподготовленных пользователей в России, которые вставляют ссылку на подписку, и на разработчиков, работающих с Claude Code, Codex и Gemini CLI.

Без телеметрии. Без реферальных ссылок.

Лицензия: GPL-3.0, см. [LICENSE](LICENSE). Сторонние компоненты: [NOTICE](NOTICE).

## Что Zatvor отправляет

Zatvor обращается к серверу подписки только когда вы добавляете или обновляете подписку. Автоматических фоновых запросов в версии 1a нет. Телеметрии нет.

В запросе к провайдеру уходит:

- Адрес вашей подписки (в нём обычно лежит ваш токен). Он хранится только в зашифрованном файле и не попадает в логи и сообщения об ошибках.
- `User-Agent`. По умолчанию `Zatvor/<версия> (<ОС>)`. В профиле можно выбрать `Zatvor/<версия> (<ОС>; happ-compatible)` или подпись Happ вида `Happ/<версия>/<ОС>/zatvor`. Подпись Happ выбирайте только осознанно: это выдача себя за другой клиент.
- `Accept-Encoding: gzip`.
- `x-hwid`: 32 шестнадцатеричных символа, посчитанных как HMAC-SHA256 от идентификатора машины и хоста подписки ([ADR 0008](docs/decisions/0008-hwid-algorithm.md)). Из него нельзя восстановить идентификатор машины, а у каждого провайдера он свой. Он отправляется всегда: по нему провайдер считает устройства. Поэтому первый запрос регистрирует устройство у провайдера.
- `x-device-os`, `x-ver-os`, `x-device-model`: название и версия ОС и модель устройства. Отправляются по умолчанию. Их можно выключить переключателем «отправлять данные об устройстве» (`SendDevice`) в настройках подписки; `x-hwid` при этом остаётся.

Чего нет: имени пользователя, имени компьютера, списка программ, cookie. Запрос игнорирует настройки прокси ОС и идёт напрямую.

Если сервер перенаправляет на другой хост, заголовки `x-hwid` и `x-device-*` не передаются дальше. Заголовок `Referer` (в нём был бы адрес подписки с токеном) не отправляется ни при каком перенаправлении. Переход с https на http запрещён.

Проверка задержки серверов: только когда вы её запускаете, Zatvor делает HTTP-запрос GET к `https://www.gstatic.com/generate_204` через каждый проверяемый сервер (через Xray, не напрямую с вашего адреса). Запрос не несёт данных о вас.

Остальное сетевое поведение: проверенная загрузка Xray-core с официальных релизов GitHub (запрос без данных о вас) и, начиная со стадии 1b, проверка связи через туннель. Данные о вас никуда не отправляются.
